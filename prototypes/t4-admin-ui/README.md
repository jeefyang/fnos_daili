# T4 托管台界面原型

这是 T4（#6）的一次性界面原型，用来把「新建代理应用 → 生成 → 安装」的字段、默认值和失败反馈摆到桌面上讨论；不是产品代码，不会合并进主实现。

## 打开

直接用浏览器打开 `index.html`，不需要构建或启动服务。

- 默认路由：`index.html`
- 指定变体：`index.html?variant=A`、`?variant=B`、`?variant=C`
- 底部浮动条可切换变体；也支持键盘左右方向键。
- 页头「字段清单」按钮会列出字段、必填/高级/隐藏状态与默认值。
- 「新建代理应用」里的「演示安装失败」开关可看失败停在安装步骤的样子。

## 三个变体（结构刻意不同，供挑一个方向）

| 变体 | 结构 | 适合 |
| --- | --- | --- |
| A 向导式 | 四步：目标 → 应用信息 → 入口 → 生成安装；左侧步骤条，右侧入口预览 | 第一次使用、字段多、希望一步一步来 |
| B 工作台式 | 深色左侧应用列表 + 右侧单页表单 + sticky 入口预览 | 经常新建/切换、把托管台当控制台 |
| C 清单式 | 纸质账本列表 + 文档式表单 + 右侧实时 manifest 树 | 想让「生成什么包」透明可核对 |

## 原型里已经表达的行为

- 目标只接受 origin（`scheme://host[:port]`），省略协议按 http；拒绝 path/query/#。
- 填目标后自动建议 `proxy.<host>.<port>.<4hex>` 的 appname、display_name 和描述；appname 可改。
- 反代是默认模式；直连是可选模式，入口仍为 `type=url`、`path=/`。
- 端口只读、自动分配；页面上展示「将写入 manifest 的端口」。
- 编辑已安装应用时 appname 锁定，提供「另存为新应用」；保存意味着重新生成并重装。
- 安装失败停在「安装」这一步，保留下载 fpk、查看日志、重试。
- 列表不假装有实时健康检查，只显示已记录的状态。
