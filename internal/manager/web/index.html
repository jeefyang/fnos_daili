先填目标地址

只接受 origin，例如 http://192.168.1.10:8123。不要带路径、查询串或片段。

省略协议时按 http 处理；省略端口时按 80/443 处理。

给这个应用起个名字

显示名称出现在飞牛桌面；appname 是安装目录与入口 ID 的根，首次安装后不可更改。

3–32 位，字母或数字开头，可用 . _ -；前缀/后缀可在右上角“设置”里统一配置。
PNG/JPEG/ICO，建议正方形 256×256 以上，最大 2MB；“从站点获取”会读取目标页的图标声明并回退到 /favicon.ico，只在点按时访问目标。保存时自动裁成 256 与 64 两档。
高级：版本号
默认 1.0.0，不自动递增；同版本可重装。

入口与访问方式

反代会把目标整站搬到飞牛入口下；直连只做一次 302，后续由浏览器直接访问目标。

反代入口是独立 origin；内嵌可能受目标站 CSP/X-Frame-Options 限制。
目标域名由这一台解析器查询；只在反代模式生效。系统 DNS 不可用时填一个可达的 IP。

确认并生成

生成后会调用应用中心安装；升级会先卸载旧版本，失败时尽量回滚到上一版。
